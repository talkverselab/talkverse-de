## 칸 1 — 명사 성 점 + 단어 시트 (리더 스크립트)

① **무엇**: 대화 스크립트의 독일어 줄에서 명사 앞에 성 점을 찍는다 — der ● 파랑 `#1E88E5`, die ● 빨강 `#E53935`, das ● 초록 `#43A047`(앱에 이미 있는 성 색).
명사를 누르면 아래에서 시트가 올라와 **관사+명사 · 복수형 · 복합명사 분해 · 그 명사의 장면 그림**을 보여 준다. 예: `der Apfelkuchen` → `der Apfel` + `der Kuchen`(마지막 낱말이 성을 정한다) · 복수 `die Apfelkuchen`.
② **어디**: 리더 왼쪽 「대화 스크립트」의 독일어 줄(점은 글자 앞 6pt, 줄 높이 안 바뀜). 시트는 오른쪽 칸 아래 40%(장면 컷은 위로 밀리되 말풍선 유지). 폰은 화면 아래 시트.
③ 레이아웃(아이패드 가로, 리더 전체 화면):
```
┌───────────────────────────────┬──────────────────────────────────────┐
│ 대화 스크립트                  │ ┌──────────────────────────────────┐ │
│ 1 ● Lena  Was möchtest du      │ │  [장면 컷 — 베를린 카페, 레나·나]  │ │
│           trinken?             │ │        ( Was möchtest du … )     │ │
│   바스 뫼히테스트 두 트링켄?     │ └──────────────────────────────────┘ │
│   뭐 마실래?                    │ ┌ 단어 시트 ─────────────────────── ┐ │
│ 2 ● 나    Einen ●Kaffee, bitte. │ │ ● der Kaffee   커피    🔊          │ │
│ 3 ● Lena  Ich nehme einen ●Tee  │ │ 복수  die Kaffees                  │ │
│ 4 ● 나    Ist der ●Apfelkuchen… │ │ 분해  der Apfel + der Kuchen       │ │
│                                │ │       └ 마지막 낱말이 성을 정해요   │ │
│                                │ └───────────────────────────────────┘ │
├───────────────────────────────┴──────────────────────────────────────┤
│ ▶  ━━━━━━●━━━━━━━  0.8× 1.0×  [Deutsch][메모][독음][한국어]  [성 점]   │
└──────────────────────────────────────────────────────────────────────┘
```
④ 토큰: 스크립트 독일어 17pt w600 `#0A2540`, 독음 13pt `#6B7C93`, 한국어 13pt `#425466`; 성 점 6pt 원; 시트 제목 20pt w700, 행 15pt, 패딩 16·간격 8, 모서리 18, 테두리 `#E6EBF1`, 그림자 kCardShadow. 하단 칩에 **[성 점]** 하나 추가(끄면 점 숨김).
- 데이터: 명사 사전(관사·복수·분해)이 필요 — 지금은 없음(콘텐츠 작성 금지 기간). 사전이 없으면 점·시트를 감추고 지금 화면 그대로.

## 칸 2 — du / Sie 배지 (장면 컷)

① **무엇**: 편마다 그 장면이 반말(du)인지 존댓말(Sie)인지 장면 컷 왼쪽 위에 작은 배지로 — `du · 친구 사이` / `Sie · 처음 보는 사람`. 대화 중 바뀌는 편(„Wollen wir uns duzen?")은 바뀌는 턴에서 배지가 `Sie → du` 로 넘어가고 스크립트 그 줄 옆에 작은 ↔ 표시.
② **어디**: 리더 오른쪽 장면 컷 왼쪽 위(말풍선과 반대쪽 모서리), 회화 홈의 편 카드 오른쪽 위. 
③ 레이아웃:
```
┌ 장면 컷 ───────────────────────────┐   편 카드(회화 홈)
│ [Sie · 처음 보는 사람]              │   ┌──────────────────────────┐
│                                     │   │ ☕ 카페에서        [Sie]  │
│      (점토 인형 장면)               │   │ 8턴 · 이야기              │
│                    ( Ja, gerne! )   │   └──────────────────────────┘
└─────────────────────────────────────┘
```
④ 토큰: 배지 높이 24, 글자 12pt w700, du = 인디고 `#635BFF` 바탕 10% + 글자 `#4B44D6`, Sie = 슬레이트 블루 `#56637F` 바탕 10% + 글자 `#434E66`, 모서리 12, 안쪽 여백 가로 10.
- 데이터: 편에 `register: du|Sie`(+ 바뀌는 턴 번호) 칸 하나. 회화를 새로 쓸 때 넣는다(지금 초안 5편은 전부 du).

## 바꾸지 않는 것
- 홈(오늘의 컷·이어서 읽기·메뉴), 회화 홈, 그림 카드, 진행 탭 성과(세는 것 = 편 완주·카드 맞음·핵심 표현·커버율 / 안 세는 것 = 앱 오픈·스트릭·포인트·순위), 톤(흰 바탕·남색·슬레이트 블루 그라데이션·인디고 선택).
