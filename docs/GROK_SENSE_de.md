# 언어감각 과정 대화 쓰기 규칙 (독일어, Grok 「빠른」)

한국어 화자가 독일어의 걸림돌 하나를 **설명 없이 통째로 외워서** 몸에 익히는 10줄 대화를 쓴다. 첨부 JSON 한 개 = 한 급.

- 인물: Minjun(한국인 남자, 베를린에서 독일어를 배움)과 Lena(베를린 토박이 여자 친구). 첨부에 다른 인물이 있으면 그 인물도.
- 정확히 **10줄**. 화자는 번갈아도 되고 한 사람이 두 줄 이어도 된다.
- 한 줄 = 독일어 한 두 문장, 6~14단어. 일상 회화 안에서 반전·설렘·웃음 한 번(비현실 소동 금지). 수위 12+.
- 첨부의 `target`(이 급의 걸림돌)이 **10줄 모두에 한 번 이상** 나오게 한다. `avoid` 에 적힌 것은 쓰지 않는다.
- 걸림돌이 되는 조각을 `{조각|번호}` 로 감싼다. 같은 번호를 한국어 번역에서도 그 뜻에 해당하는 조각에 붙인다(색으로 짝을 보여 준다). 한 줄에 1~4개, 번호는 줄마다 1부터.
  예: `Ich habe {den|1} Schlüssel {vergessen|2}.` / `나 열쇠{를|1} {깜빡했어|2}.`
- 한국어는 자연스러운 말투(직역 금지), 독일어의 du/Sie 를 반말/존댓말로 맞춘다.

답 형식(이 줄들만, 다른 말 없이):
```
1 Lena: 독일어 / 한국어
2 Minjun: 독일어 / 한국어
…
10 …
한 줄 안내: (이 급에서 무엇을 외우는지 한국어 한 문장, 설명하지 말고 「문장을 외우면 저절로 익혀요」 투)
```
