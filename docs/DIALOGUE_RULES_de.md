## 3. 독일어에서 다른 점(§D — 사용자 답을 받은 뒤 적용)

1. **A9 성별판** — 독일어는 말하는 사람의 성으로 문장이 거의 바뀌지 않는다. 제안: `es_f`·`rd_f`·`ko_f` 는 사람 명사가 있는 턴에만 두고, 음성은 기존대로 모든 턴 남녀 두 판.
2. **B10 강세 부호** — 독일어 정서법에는 강세 부호가 없어 본문에 달면 틀린 독일어가 된다. 제안: 본문은 그대로, 강세는 한글 독음과 음성으로만.
3. **A11 단어 상한** — 지금 가진 목록은 1,500위(약 84%)까지라 2,000·3,000위 누적률을 잴 수 없다. 제안: 동결이 풀리면 원 말뭉치로 다시 재서 정하고, 그 전엔 2,000 유지.

## 7. 굴절 반복 점검(2026-11-08, 사용자 지시 "학습자가 굴절어에 익숙해지게, 절벽구간 단어 참고 — 절대적이진 않음")

`tools/inflection_report.py` — 편마다 같은 낱말이 두 형태 이상 나온 묶음(관사 der/den/dem, 대명사 ich/mich/mir, 동사 인칭 habe/hast/hat)과 나온 격·인칭. 28편 결과: 레벨 3~5 는 묶음 5~8, 레벨 1·2 는 2~4(소형 모델이 gib/gibst·kommst/komme 같은 동사 기본형을 놓쳐 실제보다 낮게 나온다), 레벨 0 은 인사뿐이라 0(의도). 실제로 약했던 관사 편 `r1_friends_a1` 에 동사 인칭 짝(hörst/hör, machst/mache)을 넣었다. 새 편을 쓸 때 기준: 한 편에 굴절 묶음 3개 이상 — 상대가 앞 턴의 낱말을 다른 격·인칭으로 받아치게(ich mache ↔ du machst, der Mann ↔ den Mann). 어휘는 절벽 구간 단어를 먼저 쓰되(`tools/tier_report.py`) 재미·자연스러움이 우선.

## 8. 일상이 먼저(사용자 지시 2026-11-09 "반전요소를 넣으려다보니 일상회화랑 동떨어지고 있어!! 이러면 안됨", 원칙 페이지 §9)

장면은 학습자가 실제로 겪는 일상(가게·식당·길·집·학교·직장·약속·전화)과 그 자리의 흔한 표현이 중심. 반전은 있을 법한 작은 의외성까지, 카오스도 현실에서 있을 법한 꼬임까지. 28편 점검 결과 과장된 4편을 일상 장면으로 다시 씀: r1_life_a1(폰까지 뺏김 → 부엌 「소금 좀 줄래?」, 여격 유지), r1_culture_a1(「응」 한마디로 밴드 가입 → 공연 다음 날 재킷 찾기, 현재완료 유지), r2_friends_c1(버스 안 합창 → 버스 지연·반대 방향), r2_life_c1(병 하나 규칙 스무 개 → 빈 병 보증금 Pfand). 나머지 24편은 실제 장면(빵집·기차·관청·집 보기·면접·약국 등)이라 그대로. 카오스 전체 9/28 = 32%.

- **정정(2026-11-09, 사용자 "반전요소를 왜 줄여 일상회화를 하면서도 반전요소 러브요소 플러팅요소 다 넣을 수 있어")**: 반전을 줄이지 않는다. 반전·러브·플러팅은 비율 기준대로 다 넣되, 실제 일상 장면과 표현 흐름 안에서 터지게. 다시 쓴 4편도 반전(slip·reveal·chaos 2)과 설렘 한 줄(r1_culture_a1 「너 어디 갔냐고 물어보더라」)을 유지했다.
