## 3. 독일어에서 다른 점(§D — 사용자 답을 받은 뒤 적용)

1. **A9 성별판** — 독일어는 말하는 사람의 성으로 문장이 거의 바뀌지 않는다. 제안: `es_f`·`rd_f`·`ko_f` 는 사람 명사가 있는 턴에만 두고, 음성은 기존대로 모든 턴 남녀 두 판.
2. **B10 강세 부호** — 독일어 정서법에는 강세 부호가 없어 본문에 달면 틀린 독일어가 된다. 제안: 본문은 그대로, 강세는 한글 독음과 음성으로만.
3. **A11 단어 상한** — 지금 가진 목록은 1,500위(약 84%)까지라 2,000·3,000위 누적률을 잴 수 없다. 제안: 동결이 풀리면 원 말뭉치로 다시 재서 정하고, 그 전엔 2,000 유지.
