## 개선안

GPU 없이(기존 wav 다시 묶기):
1. pack: 문장 안 쉼 상한을 0.25초로 줄이고, 말 속도가 11 글자/초 미만이면 음높이를 유지한 채 최대 1.15배로 맞춘다.

GPU 필요:
2. 참고 음성: af 를 다시 만들고 잡음 바닥 -60dB 이하만 통과시킨다. 감정 설명을 "natural conversational pace, subtle" 로 낮추고 shout·sad·worried 참고 문장을 약하게 쓴다.
3. 생성: 문장 단위로 나눠 읽히고 0.18초 간격으로 잇는다. 읽기 칸에서 「…」을 빼고 쉼은 pack 이 넣는다. 짧은 첫 말(Klar. 등)은 뒷문장과 한 조각으로 둔다.
4. 검사: 유사도 0.90 이상, 앞뒤 낱말 누락 불합격, 숫자 표기(14=vierzehn) 같게 처리, 말 속도 11~17 글자/초, 긴 쉼 0.6초 이하, 잡음 바닥 -55dB 이하.
5. 모델 비교: 참고 음성(VoxCPM2)이 문장(MOSS)보다 빠르고 대체로 깨끗하다. `r1_survival_s1` 한 편만 MOSS 개선판과 VoxCPM2 판을 만들어 사용자가 귀로 고른다. 발음의 자연스러움은 이 비교로만 판단할 수 있다.
